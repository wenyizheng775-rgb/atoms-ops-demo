# 笔试说明 · 郑文怡

## 产品

自然语言生成可预览应用，支持预检、发布公开 Demo 页、版本回滚与审计。  
发布语义：保存不可变快照并开放 `/p/:id`，非生产集群部署。

## 技术要点

- LLM：DeepSeek（服务端 Key，超时与 generate 限流）
- 产物：单页 HTML Artifact Sandbox + iframe `sandbox`
- 门禁：结构 / 可交互 / 远程脚本 / 危险协议 / 体积；运维看板额外检查 SLO 阈值
- 持久化：`data/store.json`（单实例写锁）；版本与 `releases[]` 快照追加不覆盖
- 步骤标注「编排 / 真实」：LLM、Gate、版本写入、发布为真实副作用

## 建议体验路径

1. 首页输入「运维值班看板」或点示例 → 开始构建  
2. 工作台「门禁」查看 PASS/BLOCK → 发布 → 打开公开页  
3. 迭代一句需求 → 出新版本 → 「文件」回滚 → 「审计」查看记录  
4. 打开「外部脚本预检失败（示例）」查看阻断与修复建议
