# Atoms Ops Demo · 说明

作者：郑文怡

## 产品

用自然语言生成可预览的单页应用，并支持预检、发布公开 Demo 页、版本回滚与审计。

在线体验：http://134.175.134.145/  
源码：https://github.com/wenyizheng775-rgb/atoms-ops-demo

「发布」表示保存不可变快照并开放本站 `/p/:id` 预览，不是生产集群或 CDN 部署。

## 思路与取舍

- 对齐 Atoms 的主链路：需求 → 生成 → 预览 → 迭代，而不是复刻整站 UI。
- 差异点放在运维向能力：Gatekeeper 确定性预检、发布快照、回滚、审计。
- 产物用单页 HTML 沙箱：稳定预览、便于扫描，避免伪造成完整远程沙箱却不稳定。
- 编排步骤里区分「真实」与「编排」：LLM 调用、门禁、版本写入、发布是真实副作用。

## 技术要点

- LLM：DeepSeek（Key 仅在服务端；超时与 generate 限流）
- 预览：iframe `sandbox` 加载生成 HTML
- 门禁：非空、文档结构、可交互、远程脚本、危险协议、体积；运维类页面额外检查 SLO 阈值
- 持久化：`data/store.json`（单实例写锁）；适合一台机部署，不适合多实例水平扩展

## 已完成

| 能力 | 说明 |
|---|---|
| 真 LLM 生成与多轮迭代 | 不同需求会生成不同应用 |
| 可交互预览 | 生成结果可在预览区操作 |
| 门禁约束发布 | 不通过则无法发布；失败时保留上一有效版本 |
| 发布快照 / 回滚 / 审计 | `releases[]` 追加；回滚切换实际 HTML |
| 刷新后恢复 | 项目与版本落盘 |

## 刻意未做（范围外）

| 项 | 原因 |
|---|---|
| 登录 / 多租户鉴权 | 笔试时间盒内优先主闭环 |
| 真容器沙箱 / 远程终端 | 复杂度高，与「可交付原型」目标不匹配 |
| 多 Agent 值班室大屏 | 易变成演示堆砌，收益低于门禁与发布 |

## 若继续投入（优先级）

1. 持久化换 SQLite/Postgres，支持多实例  
2. 基础鉴权或演示 Token，避免公网刷 generate  
3. 门禁规则可配置（SOP 模板）  
4. 步骤流式输出（SSE）

## 建议体验路径

1. 首页选「运维看板」或自定义需求 → 开始构建  
2. 工作台「门禁」查看检查项 → 通过后发布 → 打开公开页  
3. 提交一句迭代 → 出新版本 →「文件」回滚 →「审计」查看记录
