# Atoms Ops Demo · 设计说明

作者：郑文怡

## 产品

用自然语言生成可预览的单页应用，并支持预检、发布公开 Demo 页、版本回滚与审计。

- 在线：http://134.175.134.145/
- 源码：https://github.com/wenyizheng775-rgb/atoms-ops-demo

「发布」表示保存不可变快照并开放本站 `/p/:id` 预览，不是生产集群或 CDN 部署。

## 思路与取舍

- 对齐 Atoms 主链路：需求 → 生成 → 预览 → 迭代，不复刻整站 UI。
- 差异点：Gatekeeper 确定性预检、发布快照、回滚、审计。
- 产物用单页 HTML 沙箱：稳定预览、便于扫描。
- 步骤区分「真实 / 编排」：LLM、门禁、版本写入、发布为真实副作用。

## 技术要点

- LLM：DeepSeek（Key 仅服务端；超时与限流）
- 预览：iframe `sandbox`
- 门禁：结构、可交互、远程脚本、危险协议、体积；运维页额外检查 SLO 阈值
- 持久化：`data/store.json`（单实例）；不适合多实例水平扩展

## 已完成 / 刻意未做

已完成：真 LLM 生成与迭代、可交互预览、门禁约束发布、发布快照与回滚审计、刷新恢复。

刻意未做：登录与多租户、真容器沙箱、多 Agent 大屏——优先保证可交付主闭环。

## 建议体验

1. 首页选示例或自定义需求 → 开始构建  
2. 「门禁」通过后发布 → 打开公开页  
3. 迭代 → 回滚 → 查看「审计」
